# Vulcan IDE (EndeavourOS / Wayland)

Host-side GTK4 editor. Not part of the ESP-IDF firmware build.

```bash
sudo pacman -S python-gobject gtk4 python-pyserial
sudo usermod -aG uucp "$USER"
./vulcan-ide
```

Target: This PC or Watch. Tyrant mode: PC orders the watch over USB-C serial (`<<VUL` / `TY IO`).
